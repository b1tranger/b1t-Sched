# Implementation Plan - Google Classroom Unified Pre-Fetching, Reconnect Re-Fetching & Incremental Skip Tracking

Update the caching and data fetching architecture in [classroom.js](file:///c:/Users/.../Documents/GitHub/%5BoU1TS%5D/b1t-Sched/js/classroom.js) so that:
1. Assignments, notices, and materials from all views (unified and course-wise) are fetched together on initial load/login, eliminating waiting times when switching tabs or opening individual course details.
2. Clicking **"Reconnect Classroom"** re-authenticates and re-fetches all content like initial load, using smart incremental skip tracking to identify unchanged items and skip redundant work.
3. When the Google login token expires, all cached content (course list, unified To-Do/Notices/Materials, and course-wise details) continues to display seamlessly with the persistent Reconnect banner.

---

## User Review Required

> [!IMPORTANT]
> - **Unified Pre-Fetching**: On initial login/load, `Classroom` will fetch active courses, followed by assignments, announcements, and materials in parallel. 
> - **Course-Wise View Integration**: Opening individual course cards will now slice/filter from the pre-fetched cached dataset instead of firing separate blocking network requests.
> - **Reconnect Re-Fetch & Incremental Skip**: Clicking **"Reconnect Classroom"** will trigger a fresh fetch. Items with matching `id` and `updateTime` already present in cache will be recognized as unchanged and skipped during merge processing.
> - **Expired Session Navigation**: When the Google token expires, users can browse their course list ("My Classes"), filter course-wise items, and switch tabs seamlessly off cached data while displaying the sticky bottom `"Cached Content, login again to see new data"` bar and `Reconnect Classroom` button.

## Proposed Changes

### Google Classroom Module

#### [MODIFY] [classroom.js](file:///c:/Users/.../Documents/GitHub/%5BoU1TS%5D/b1t-Sched/js/classroom.js)

1. **Unified Data Pre-Fetching (`fetchAllData`)**:
   - Refactor `fetchCoursesAndLoadAll()` to fetch active courses and trigger a combined `fetchAllData()` method using `Promise.allSettled`.
   - `fetchAllData()` will simultaneously retrieve:
     - Assignments (`loadAllAssignments({ silent: true })`)
     - Announcements (`loadAllAnnouncements({ silent: true })`)
     - Materials (`loadAllMaterials({ silent: true })`)
   - Store all 3 datasets into `CacheManager` and `saveJsonCache`.
   - Also persist active and archived `courses` inside the JSON cache template (`jsonCache.courses`).

2. **Smart Incremental Skip Tracking (`mergeAndSkipUnchanged`)**:
   - Maintain an item tracking index based on `item.id` + `item.updateTime` (or `creationTime`/`dueDate`).
   - When **"Reconnect Classroom"** or `refreshData()` runs:
     - Compare newly fetched API items with the existing cached items map.
     - Skip deep re-parsing/updating for unchanged items that are already loaded (`id` and `updateTime` match).
     - Merge new, updated, or removed items into the cache seamlessly and update `saveJsonCache`.

3. **In-Memory & Cache-First Course-Wise Views**:
   - Update `openCourse(courseId)` and `switchView(view)`:
     - Check if assignments, announcements, or materials exist in memory/cache.
     - For course-wise views, filter the pre-fetched dataset by `item.courseId === courseId` instead of making individual course API calls (`fetchCourseWork`, `fetchAnnouncements`, `fetchCourseMaterials`).
     - Keep full fallback to single-course API calls if data is missing while online.

4. **Seamless Expired Session Navigation**:
   - Refactor `renderCourseList()` to support cached display:
     - When `hasExpiredSession = true` or `!this.accessToken`, retrieve cached `courses` from `getJsonCache()` / `CacheManager`.
     - Render course cards and display the persistent bottom banner & `Reconnect Classroom` button.
   - Refactor `showCachedDataWithBanner()` & `switchView(view)`:
     - Support rendering cached data for both Unified View (`currentCourseId == null`) and Course-Wise View (`currentCourseId != null`).
     - Seamlessly allow switching between To-Do, Notices, and Materials tabs when offline/expired without making network calls.
