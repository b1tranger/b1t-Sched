# Walkthrough - Google Classroom Unified Pre-Fetching, Reconnect Re-Fetching & Incremental Skip Tracking

I have updated the caching, data pre-fetching, and token expiration logic in [js/classroom.js](file:///c:/Users/.../Documents/GitHub/%5BoU1TS%5D/b1t-Sched/js/classroom.js):

## Key Changes Implemented

1. **Unified Batch Data Pre-Fetching (`fetchAllContentData`)**:
   - On initial login or load, `Classroom.fetchCoursesAndLoadAll()` fetches active courses and executes a batch parallel load (`Promise.allSettled`) retrieving:
     - **Assignments** (`fetchAssignmentsData`)
     - **Announcements / Notices** (`fetchAnnouncementsData`)
     - **Materials** (`fetchMaterialsData`)
   - All three content types as well as active/archived courses are pre-fetched and stored together in `CacheManager` and the structured client JSON template (`saveJsonCache`).

2. **Smart Incremental Skip Tracking (`mergeAndSkipUnchanged`)**:
   - Added item fingerprinting comparing `item.id` and timestamp (`updateTime` / `creationTime` / `dueDate`).
   - When **"Reconnect Classroom"** or `refreshData()` is clicked, newly fetched API items are merged with existing cached items.
   - Items that match both `id` and `updateTime` are recognized as unchanged and skipped during re-parsing/re-rendering to prevent redundant DOM updates and conserve client processing.

3. **In-Memory & Cache-First Course-Wise Slicing (`getOrFetchData` & `renderCurrentView`)**:
   - Navigating to individual courses (`openCourse(courseId)`) or switching tabs (**To-Do**, **Notices**, **Materials**) now extracts/filters directly from the pre-fetched dataset in memory/cache without initiating new network calls or making the user wait.

4. **Seamless Navigation on Expired Session**:
   - When the Google OAuth token expires (`hasExpiredSession = true` or no token):
     - **Course List ("My Classes")**: Displays cached course cards alongside the sticky bottom banner (`"Cached Content, login again to see new data"`) and **"Reconnect Classroom"** button.
     - **Unified Feeds**: Displays cached To-Do, Notices, or Materials with the sticky Reconnect bar.
     - **Course-Wise Views**: Filters cached items for the selected course with the sticky Reconnect bar.
     - **Tab Toggling**: Allows switching tabs smoothly without throwing network errors.
   - Clicking **"Reconnect Classroom"** launches Google re-authentication (`Classroom.login()`) and triggers a fresh batch fetch with incremental skip tracking upon authorization.
