### AI Thought

1. **Analyze User Issue & Root Cause**:
   - **Target Modal**: `#changelog-modal` ("What's New in b1t-Sched") defined in `index.html` (lines 2193–2227).
   - **Problem**: When a user arrives at the website or reloads while unauthenticated, the modal pops up immediately over the login screen (`#login-view`).
   - **Root Cause Investigation**:
     - Inspected `js/changelog-modal.js`.
     - In `js/changelog-modal.js`, the script executed `ChangelogModal.init()` immediately on `DOMContentLoaded`.
     - `ChangelogModal.init()` was invoking `await this.checkAndShowChangelog()`.
     - Because this occurred during DOM load before Firebase auth state was evaluated, any mismatch between `changes.json` `currentVersion` and `localStorage.getItem('b1t_last_seen_version')` resulted in `ChangelogModal.open()` running on top of the unauthenticated login screen.

2. **Formulate Solution Strategy**:
   - **Decouple Auto-Show from DOM Initialization**:
     - `ChangelogModal.init()` should only bind event listeners (close button, got it button, manual profile settings trigger, footer link trigger, backdrop click, and Escape key listener). It should NOT call `this.checkAndShowChangelog()`.
   - **Guard `checkAndShowChangelog(forceOpen)`**:
     - When `forceOpen` is `false` (auto-popup check), verify that:
       1. The user is logged in (`Auth.getCurrentUser()` or `firebase.auth().currentUser` exists).
       2. The active route is `'dashboard'` or `#dashboard-view` is visible (`display !== 'none'`).
     - When `forceOpen` is `true` (e.g., user clicks "View Changelog" in Profile Settings or Footer), bypass route/auth guards and display immediately.
   - **Integrate with Dashboard Lifecycle in `js/app.js`**:
     - In `loadDashboardData()`: Call `ChangelogModal.checkAndShowChangelog()` alongside `this.initHomeSemesterNotice()` so version updates display automatically when the dashboard finishes rendering for the logged-in user.
     - In `handleUnauthenticatedUser()`: Call `ChangelogModal.close()` to ensure any open modal is dismissed upon logout.

3. **Code Implementation**:
   - **`js/changelog-modal.js`**:
     ```javascript
     init() {
       console.log('[ChangelogModal] Initializing...');
       this.setupEventListeners();
     },
     ```
     ```javascript
     async checkAndShowChangelog(forceOpen = false) {
       if (!forceOpen) {
         const currentUser = (typeof Auth !== 'undefined' && typeof Auth.getCurrentUser === 'function')
           ? Auth.getCurrentUser()
           : (window.firebase && firebase.auth ? firebase.auth().currentUser : null);

         const currentRoute = (typeof Router !== 'undefined' && typeof Router.getCurrentRoute === 'function')
           ? Router.getCurrentRoute()
           : null;

         const dashboardView = document.getElementById('dashboard-view');
         const isDashboardVisible = dashboardView && dashboardView.style.display !== 'none';

         if (!currentUser || (currentRoute !== 'dashboard' && !isDashboardVisible)) {
           return;
         }
       }

       const data = await this.fetchChanges();
       if (!data || !data.currentVersion) return;

       const lastSeenVersion = localStorage.getItem(this.storageKey);
       const currentVersion = data.currentVersion;

       if (forceOpen || !lastSeenVersion || lastSeenVersion !== currentVersion) {
         this.render(data);
         this.open();
       }
     },
     ```
   - **`js/app.js`**:
     - In `loadDashboardData()`:
       ```javascript
       this.updateUserCount();
       this.initHomeSemesterNotice();

       // Check and show changelog modal if new version is available
       if (typeof ChangelogModal !== 'undefined' && typeof ChangelogModal.checkAndShowChangelog === 'function') {
         ChangelogModal.checkAndShowChangelog();
       }
       ```
     - In `handleUnauthenticatedUser()`:
       ```javascript
       // Hide changelog modal if open
       if (typeof ChangelogModal !== 'undefined' && typeof ChangelogModal.close === 'function') {
         ChangelogModal.close();
       }
       ```

4. **Verify Implementation**:
   - Checked file contents and diffs across `js/changelog-modal.js` and `js/app.js`.
   - Verified that manual triggers from Profile Settings (`#profile-view-changelog-btn`) and footer (`#footer-changelog-link`) continue working seamlessly via `checkAndShowChangelog(true)`.
