## Changes Made

### Google Classroom & Cache Manager

#### [cache-manager.js](file:///c:/Users/.../Documents/GitHub/%5BoU1TS%5D/b1t-Sched/js/cache-manager.js)
- Added `CLASSROOM_MATERIALS: 'classroom-materials'` cache key.
- Added `_getClassroomKey(type)` helper method supporting `'materials'`, `'assignments'`, and `'announcements'`.
- Updated `cacheClassroomData`, `getCachedClassroomData`, `clearUserCaches`, and `pruneOldCaches` to manage cached course materials.

#### [classroom.js](file:///c:/Users/.../Documents/GitHub/%5BoU1TS%5D/b1t-Sched/js/classroom.js)
- **Materials Scope**: Added `https://www.googleapis.com/auth/classroom.courseworkmaterials.readonly` to OAuth scopes.
- **Materials View**: Added `loadAllMaterials()` and `fetchCourseMaterials(courseId)` methods to fetch posted materials from Google Classroom REST API (`/courseWorkMaterials`).
- **View Toggle**: Added **Materials** toggle button next to **To-Do** and **Notices** in both the unified view header and individual course view headers.
- **Archived Classrooms**:
  - Updated course fetching query to `courseStates=ACTIVE&courseStates=ARCHIVED`.
  - Archived courses are hidden by default in the "My Classes" list.
  - Added a **"Show archived classrooms"** toggle button at the end of the course list.
  - Ensured the unified view (`loadAllAssignments`, `loadAllAnnouncements`, `loadAllMaterials`) explicitly skips archived courses (`courseState !== 'ACTIVE'`).
- **Sign Out Button Visibility**:
  - Added `updateLogoutButtonVisibility()` method.
  - Dynamically shows header Sign Out buttons (`#logout-classroom-sidebar` and `#logout-classroom-modal`) when connected/logged in, and hides them when logged out.

#### [index.html](file:///c:/Users/.../Documents/GitHub/%5BoU1TS%5D/b1t-Sched/index.html)
- Added `style="display: none;"` to `#logout-classroom-sidebar` and `#logout-classroom-modal` so header Sign Out buttons start hidden when unauthenticated.

#### [classroom.css](file:///c:/Users/.../Documents/GitHub/%5BoU1TS%5D/b1t-Sched/css/classroom.css)
- Added `.item-icon.material` badge style (amber/orange material background).
- Added `.show-archived-btn` button styling.
