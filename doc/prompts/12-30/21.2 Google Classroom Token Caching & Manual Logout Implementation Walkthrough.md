# Google Classroom Token Caching & Manual Logout Implementation Walkthrough

We have updated the Google Classroom integration to prevent frequent forced logouts when access tokens expire, and added a manual Sign Out feature across all Classroom UI views.

## Key Changes Made

### 1. Token Caching & Session Persistence (`js/classroom.js`)
- **Connection Preservation**: `localStorage.setItem('classroom_connected', 'true')` is now preserved when a 1-hour access token expires. The application no longer purges user connection flags on token expiry.
- **Silent Refresh Attempt**: When opening Classroom or checking sessions, the application attempts a silent token refresh (`tokenClient.requestAccessToken({ prompt: 'none' })`).
- **Cached Data Fallback**: If silent refresh is blocked by browser 3rd-party cookie policies, the app serves cached assignments/announcements from `CacheManager` with a "Session expired · Reconnect" banner instead of forcing a full sign-out.
- **Benign Error Handling**: `_handleAuthError` distinguishes between `interaction_required` / `access_denied` during silent refresh and hard authentication failures, keeping the user connected in cached mode until reconnected or explicitly logged out.

### 2. Manual Sign Out Functionality (`js/classroom.js`, `js/facultyClassroom.js`, `index.html`, `css/classroom.css`)
- **Header Logout Buttons**: Added Sign Out buttons to:
  - Mobile Sidebar Header (`#classroom-sidebar .classroom-header`)
  - Desktop Modal Header (`#classroom-modal .classroom-modal-header`)
  - "All Courses" View Header (`renderAllItems`)
  - "Course Details" View Header (`renderCourseDetails`)
  - "My Classes" View Header (`renderCourseList`)
  - Session Expired Banner (`renderExpiredSessionBanner`)
- **Revocation & Cleanup**: `Classroom.logout()` revokes the Google OAuth access token, removes connection flags (`classroom_connected`, `classroom_token`, `classroom_token_expiry`), clears the Cache API storage, and resets the view to the initial Google Sign-In state.
- **Faculty Module Integration**: Added `FacultyClassroom.logout()` delegating to `Classroom.logout()`.
- **CSS Styling**: Added `.classroom-header-logout-btn` with dark/light mode support in `css/classroom.css`.

## Verification Steps
1. **Sign In**: Click "Sign in with Google" in the Classroom panel and authorize access. Verify courses & assignments load.
2. **Session Persistence**: Simulate an expired 1-hour access token by setting `classroom_token_expiry` to a past timestamp in Local Storage. Reload the page and open Classroom. Confirm the user remains connected and cached data is displayed with a Reconnect button instead of wiping connection data.
3. **Manual Logout**: Click "Sign Out" from the Desktop Modal header, Mobile Sidebar header, or view headers. Verify that access token is revoked, cached data is cleared, and the UI returns to the initial Google Sign-In prompt.
