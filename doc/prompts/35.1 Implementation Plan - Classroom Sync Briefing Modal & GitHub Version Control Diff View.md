# Implementation Plan - Classroom Sync Briefing Modal & GitHub Version Control Diff View

Replace plain JavaScript `alert()` dialogs in Google Classroom sync with an interactive, GitHub-styled sync briefing modal. The modal summarizes updated and added assignments/announcements, provides direct links to the original posts, and renders expandable side-by-side version control diffs (commit history style) for line-by-line instructions/captions, deadline changes, and added/removed attachments.

## User Review Required

> [!NOTE]
> - The new briefing modal replaces all legacy `alert()` alerts during Classroom sync (`Classroom.syncAssignmentsToTasks`).
> - The diff view matches GitHub commit history styling (split/side-by-side monospace diff table, green/red line markers and highlights, line numbers, file addition/removal badges).
> - Each item in the sync summary is collapsed by default and displays a "View Changes" dropdown toggle button to inspect the diff on demand.

## Proposed Changes

### 1. Line-by-Line & Attribute Diff Engine

#### [MODIFY] [js/classroom.js](file:///d:/GitHub/[oU1TS]/b1t-Sched/js/classroom.js)
- Implement `computeLineDiff(oldText, newText)` using a Longest Common Subsequence (LCS) algorithm to generate line-by-line addition, deletion, and unchanged chunks with line numbers.
- Implement `computeItemDiff(existingTaskOrItem, newItem)` to extract:
  - Title changes (old title vs new title).
  - Deadline/due date changes (old formatted date vs new formatted date).
  - Caption / instruction / description line diff.
  - File / attachment diff (added attachments with links, removed attachments).
- Update `syncAssignmentsToTasks()` to:
  - Track all synced items with their change status (`added`, `updated`, `unchanged`) and full diff payloads.
  - Open `Classroom.showSyncSummaryModal(syncResults)` instead of `alert(...)`.
  - Also handle the 0-change case gracefully inside the modal briefing.

## Verification Plan

### Manual Verification
1. **Trigger Sync with New Assignment**:
   - Click "Sync" in Classroom modal.
   - Verify `#classroom-sync-modal` opens with a briefing card showing `+ Added Task`.
   - Click "View in Classroom" link button and ensure it opens the Google Classroom post in a new tab.
   - Click "View Changes" dropdown toggle and verify the Git-styled diff view displays all added lines in green with line numbers.
2. **Trigger Sync with Updated Instructions/Caption/Deadline**:
   - Update an assignment's description or deadline in Classroom.
   - Click "Sync" and verify the card shows `~ Updated`.
   - Click "View Changes" dropdown and verify the side-by-side diff clearly highlights changed lines (red for deletions, green for additions), deadline changes, and any added/removed file attachments.
3. **Trigger Sync when Up to Date**:
   - Click "Sync" again when no changes are present.
   - Verify modal shows a clean "All assignments are up to date" summary without errors.
4. **Theme & Responsiveness**:
   - Verify dark mode, gray mode, and light mode aesthetic consistency.
   - Verify responsive behavior on desktop and mobile viewports.
