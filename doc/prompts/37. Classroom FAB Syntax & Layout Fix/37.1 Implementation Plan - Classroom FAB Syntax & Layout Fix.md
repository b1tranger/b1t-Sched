# Implementation Plan - Classroom FAB Syntax & Layout Fix

## Overview
Resolve broken HTML syntax on the Google Classroom Create Announcement / Assignment floating action buttons (`#classroom-create-btn-desktop` and `#classroom-create-btn-mobile`) in `index.html`. Unclosed attributes were accidentally rendered as inner text inside the button elements, corrupting the circular 50x50px FAB geometry and visual styling.

## User Request
```html
the css on the following code for "New Class Announcement / Assignment" seems to be broken:

<button id="classroom-create-btn-desktop" class="classroom-create-fab" onclick="Classroom.openCreateModal()" title="Create announcement or assignment" style="display: flex;">
                        onclick="Classroom.openCreateModal()" title="Open Google Classroom"
                        aria-label="Open Google Classroom"&gt;
                        <i class="fas fa-plus"></i>
                    </button>
```

## Proposed Changes

### 1. `index.html`
- Correct lines 946-952 and 1046-1052:
  Remove the duplicate/broken unclosed text `onclick="Classroom.openCreateModal()" title="Open Google Classroom" aria-label="Open Google Classroom">` from the inner body of both `#classroom-create-btn-mobile` and `#classroom-create-btn-desktop`.
- Ensure clean button markup with proper title and `aria-label`:
  ```html
  <button id="classroom-create-btn-desktop" class="classroom-create-fab"
      onclick="Classroom.openCreateModal()" title="Create announcement or assignment"
      aria-label="Create announcement or assignment"
      style="display: none;">
      <i class="fas fa-plus"></i>
  </button>
  ```
- Update changelog version badge to `v2.53.0 to v2.53.17`.

### 2. `css/classroom.css`
- Ensure `.classroom-create-fab` has `padding: 0; line-height: 1;` to reset any browser default button padding/spacing that could distort the 50x50px circular geometry.

### 3. Versioning & Changelogs
