# Implementation Plan - Faculty & Student ID Login, 3-Row Install Prompt & Login Scroll Reset

Address credential flexibility for student and faculty login, redesign the PWA install prompt into a solid 3-row layout, and eliminate downward scroll jump on login page load/logout.

## Proposed Changes

### 1. Authentication & Credentials Support
- **Sign-up page**: Restrict to email input only (`type="email"` and email format validation).
- **Set-details page**: Retain `pattern="[0-9]{10,16}"`, `minlength="10"`, `maxlength="16"` and `/^[0-9]{10,16}$/` validation for students so they must input their 10-16 digit student ID.
- **Login page Student mode**: Allow student login with student ID and password. In `DB.getEmailByStudentId(rawInput)`, normalize ID (support with/without dashes and spaces, string/numeric in Firestore) and resolve email to log in with password.
- **Login page Faculty mode**: Allow faculty login with Faculty ID or Initials (or email) and password. In `DB.getEmailByFaculty(rawInput)`, check `facultyInitial`, `studentId`, and `facultyId` (case-insensitive & numeric conversions) in memory without compound composite queries, resolving email to log in with password. Update placeholder and hint accordingly.

### 2. Web App Install Prompt: 3-Row Layout & Solid Themed Background
- **3-Row Layout Structure (`index.html`, `css/components.css`)**:
  - Row 1: App icon + `<h3>Install b1t-Sched</h3>`
  - Row 2: `<p class="install-desc">Install our app for quick access and offline use</p>`
  - Row 3: `.install-actions` containing `Install` and `Not now` buttons.
- **Solid Themed Background (`css/colors.css`, `css/components.css`)**:
  - Define `--bg-card: var(--bg-white);` across `:root`, `body.dark-mode`, and `body.gray-mode`.
  - Set solid opaque backgrounds:
    - Light Mode: `#ffffff`
    - Dark Mode (`body.gray-mode`): `#242424`
    - High Contrast (`body.dark-mode`): `#141414`
  - Ensure high-contrast text and solid borders across all themes.

### 3. Prevent Downward Scroll on Login Refresh & Logout
- Enforce `history.scrollRestoration = 'manual'` in `Router.init()`.
- Reset viewport scroll (`window.scrollTo({ top: 0, left: 0, behavior: 'instant' })`) on:
  - Route view changes in `Router.showView()`
  - User logout in `Auth.logout()`
  - Unauthenticated redirection in `App.handleUnauthenticatedUser()`
  - Loading dismissal in `UI.showLoading(false)` when on login view.

## Verification Plan
- Validate student ID lookup and faculty ID/initial lookup without Firestore composite index errors.
- Confirm install prompt displays in 3 distinct rows with solid backgrounds in Light, Dark, and High Contrast modes.
- Verify login page stays anchored to top on refresh and after logout.
