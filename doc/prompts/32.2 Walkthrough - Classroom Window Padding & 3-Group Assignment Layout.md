# Walkthrough - Classroom Window Padding & 3-Group Assignment Layout

## Overview
We fixed the unwanted border padding on smaller desktop displays for the Google Classroom modal and reorganized the Assignments (To-Do) view to divide tasks into 3 distinct vertical groups, with a small-height divider banner separating tasks that have passed their due dates.

---

## Changes

### CSS Stylesheets

#### [css/responsive.css](file:///c:/Users/gsmur/OneDrive/Documents/GitHub/b1t-Sched/css/responsive.css)
- Excluded `#classroom-modal .modal-content` and `.classroom-modal-content` from generic `.modal-content` padding (`var(--spacing-lg)` and `var(--spacing-md)`).
- Enforced `padding: 0 !important;`, `width: 90%`, `max-width: 1000px`, `height: 80vh`, and `overflow: hidden;` across standard smaller desktop displays (769px–1366px) and height-constrained screens (max-height: 768px).

#### [css/classroom.css](file:///c:/Users/gsmur/OneDrive/Documents/GitHub/b1t-Sched/css/classroom.css)
- Added `padding: 0 !important;` to `.classroom-modal-content` and `#classroom-modal .modal-content`.
- Styled compact group divider banners (`.classroom-group-divider`, `.passed-due-divider`, `.completed-divider`, `.classroom-group-divider-badge`, `.classroom-group-count`) with theme support for Default, Dark Mode, and Gray Mode.

---

### Google Classroom Logic

#### [js/classroom.js](file:///c:/Users/gsmur/OneDrive/Documents/GitHub/b1t-Sched/js/classroom.js)
- Implemented robust helper functions:
  - `getAssignmentDueDate(item)`: Robustly parses Google Classroom `dueDate` object, `Date` instances, and timestamp strings.
  - `isPastDue(item, now)`: Accurately checks whether the deadline has passed.
  - `isSubmittedOrReturned(item)`: Detects if the task is turned in, graded, or returned.
  - `getAssignmentGroup(item, now)`: Categorizes tasks into Group 0 (Assigned, no due date), Group 1 (Upcoming, yet to pass due date), Group 2 (Passed due date), and Group 3 (Completed).
- Updated `sortAssignments(assignments)` to sort assignments sequentially:
  1. **Group 1**: Assigned (No due date)
  2. **Group 2**: Yet to pass due date (ascending by deadline, earliest first)
  3. **Group 3**: Passed due date (ascending by deadline)
  4. **Group 4**: Completed (Turned In, Graded, Returned)
- Added `renderTodoList(items, renderItemFn)` to render the 3-group layout:
  - Assigned tasks (no due date) at the top.
  - Tasks that have yet to pass their due date directly below assigned tasks and above overdue tasks.
  - A small-height, clear **Passed Due Date** banner with task count introducing the overdue tasks.
  - A clean **Completed** banner if completed tasks exist.
- Updated `renderAllItems` and `renderCourseDetails` when `viewType === 'todo'` to use `renderTodoList`.
