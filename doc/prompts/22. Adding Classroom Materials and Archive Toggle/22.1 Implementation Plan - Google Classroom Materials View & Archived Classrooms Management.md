# Implementation Plan - Google Classroom Materials View, Archived Classrooms & Sign Out Visibility

This plan updates the Google Classroom integration to support a new "Materials" toggle tab (listing posted course materials), manage archived classrooms (hiding archived courses by default with a toggle button), and dynamically manage the visibility of the "Sign Out" header buttons so they only show when logged in.

## User Review Required

> [!NOTE]
> The "Sign Out" header buttons (`#logout-classroom-sidebar` and `#logout-classroom-modal`) will default to hidden (`display: none`) when logged out and will dynamically display (`display: inline-flex`) when a user has an active/connected session.

### Google Classroom Module

#### [MODIFY] [classroom.js](file:///c:/Users/.../Documents/GitHub/%5BoU1TS%5D/b1t-Sched/js/classroom.js)
- Update `SCOPES` to include `https://www.googleapis.com/auth/classroom.courseworkmaterials.readonly`.
- Add `showArchivedCourses: false` state property.
- Add helper method `updateLogoutButtonVisibility()` to dynamically show or hide `#logout-classroom-sidebar` and `#logout-classroom-modal` based on whether the user is logged in / connected.
- Call `updateLogoutButtonVisibility()` in `renderInitialState()`, `renderLoginState()`, `handleAuthSuccess()`, `checkPersistedSession()`, `openClassroomParams()`, and `cleanupSession()`.
- Update `fetchCourses` and `fetchCoursesAndLoadAll` to fetch courses with query parameters `courseStates=ACTIVE&courseStates=ARCHIVED` so archived courses can be fetched once and filtered as needed.
- Add `loadAllMaterials()` function to load course work materials across all `ACTIVE` courses within the configured date cutoff (`DATE_FILTER_MONTHS`), sort them by `updateTime`/`creationTime`, and cache via `CacheManager`.
- Add `fetchCourseMaterials(courseId)` function to load materials for a single course.
- Update `switchView(view)` to handle `'materials'` in addition to `'todo'` and `'notifications'`.
- Update `renderAllItems` and `renderCourseDetails` headers to include the **Materials** toggle button alongside **To-Do** and **Notices**.
- Update `renderUnifiedListItem` and `renderListItem` to handle rendering material items (`type === 'materials'`), using icon `fa-folder-open` / `fa-book` and formatting material titles, links, and snippets.
- Update `showCachedDataWithBanner()` to support retrieving cached `'materials'`.
- Update `renderCourseList()` to:
  - Separate active courses and archived courses.
  - By default, render only active courses.
  - Render a `"Show archived classrooms"` button at the bottom of the "My Classes" container (or `"Hide archived classrooms"` when expanded).
  - Add `toggleArchivedCourses()` method to toggle `this.showArchivedCourses` state and re-render the course list.
- Ensure unified views (`loadAllAssignments`, `loadAllAnnouncements`, `loadAllMaterials`) explicitly continue to exclude archived courses (`course.courseState !== 'ACTIVE'`).

## Verification Plan

### Manual Verification
1. **Sign Out Button Visibility**:
   - Verify when unauthenticated/logged out, the header "Sign Out" button is hidden in both sidebar and modal.
   - Sign in to Google Classroom; verify the "Sign Out" button becomes visible.
   - Click "Sign Out"; verify local session is cleared and the "Sign Out" button hides again on the login screen.
2. **Materials Toggle**:
   - Open Google Classroom window while signed in.
   - Verify three view toggle buttons: **To-Do**, **Notices**, and **Materials**.
   - Click **Materials** and verify posted materials from all active courses are loaded and displayed.
   - Open a specific course and click **Materials** tab to verify single-course materials view works.
3. **Archived Classrooms**:
   - Open "My Classes" view.
   - Verify archived classrooms are hidden by default.
   - Click "Show archived classrooms" and verify archived courses become visible.
   - Switch to unified views (To-Do, Notices, Materials) and confirm archived course content is NOT included in the unified feed.
