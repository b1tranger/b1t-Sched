# Fix Plan: Resolving Firebase `auth/api-key-expired` Error

This document outlines the root cause and step-by-step guide to fix the `auth/api-key-expired.-please-renew-the-api-key.` error when logging in or resetting passwords.

---

## Root Cause Analysis

When setting up localhost environment variables in Prompt 17.2, `node inject-env.js` injected the API key from `.env`:
`FIREBASE_API_KEY="AIzaSyAMc_2g2zK8DYbugsaf4JEYWCYftoxIdkE"`

This key (`AIzaSyAMc...`) is either **expired, revoked, restricted, or deleted** in the Firebase / Google Cloud Console. Consequently, calls to Firebase Identity Toolkit (`accounts:signInWithPassword`, `accounts:sendOobCode`) return an HTTP 400 response with error `auth/api-key-expired.-please-renew-the-api-key.`.

---

## Step-by-Step Guide: What to Do in Firebase / Google Cloud Console

### Option A: Retrieve/Renew API Key from Firebase Console (Recommended)

1. Open the [Firebase Console](https://console.firebase.google.com/).
2. Select your project: **`b1t-sched`**.
3. Click the ⚙️ **Gear Icon** (top left, next to "Project Overview") and select **Project settings**.
4. In the **General** tab, scroll down to **Your apps**.
5. Locate your Web App (App ID: `1:787498876432:web:665f5b73e21ed0e9535495`).
6. Under the SDK setup snippet, look at the **`apiKey`** field.
   - Copy the fresh/valid API key string starting with `AIzaSy...`.

---

### Option B: Renew / Restore API Key Restrictions in Google Cloud Console

If the API key was key-restricted or disabled in Google Cloud:

1. Open the [Google Cloud Console Credentials Page](https://console.cloud.google.com/apis/credentials).
2. Ensure project **`b1t-sched`** is selected at the top.
3. Under **API Keys**, locate the key corresponding to your Firebase project.
4. **Check Restrictions**:
   - **Application restrictions**: If set to *HTTP referrers (web sites)*, ensure `localhost`, `127.0.0.1`, and your Netlify domain (e.g. `https://b1t-sched.netlify.app/*`) are listed under allowed referrers.
   - **API restrictions**: If set to *Restrict key*, ensure **Identity Toolkit API**, **Firebase Management API**, and **Cloud Firestore API** are enabled.
5. If the key was deleted or auto-expired, click **+ CREATE CREDENTIALS** -> **API Key** to create a fresh key.

## Local Project Fix Instructions

After obtaining the valid API Key from Firebase:

1. **Update `.env`**:
   Open [.env](file:///c:/Users/.../Documents/GitHub/%5BoU1TS%5D/b1t-Sched/.env) and update line 1:
   ```env
   FIREBASE_API_KEY="<YOUR_NEW_VALID_FIREBASE_API_KEY>"
   ```

2. **Re-Inject Environment Variables**:
   Run the injection script from your terminal:
   ```bash
   node inject-env.js
   ```

3. **Deploy / Netlify Environment Variables** (If live site is affected):
   - Go to **Netlify Site Settings** > **Environment variables**.
   - Update `FIREBASE_API_KEY` to the new valid key.
   - Trigger a new deployment.
