# Walkthrough - Classroom Sync Briefing Modal & GitHub Version Control Diff View

Replaced plain JavaScript `alert()` notifications during Google Classroom sync with an interactive briefing modal (`#classroom-sync-modal`). The modal displays a summary of updated and added assignments/tasks, direct links to the original posts, and manual dropdown toggles rendering GitHub-style commit diff views with line-by-line additions, deletions, attachment changes, and property modifications.

## Changes Made

### 1. Line Diff & Property Comparison Engine
- **[js/classroom.js](file:///d:/GitHub/[oU1TS]/b1t-Sched/js/classroom.js)**:
  - `computeLineDiff(oldText, newText)`: Longest Common Subsequence (LCS) line diff algorithm that generates structured addition, deletion, and unchanged line chunks with line numbers and change counts (`+X`, `-Y`).
  - `extractMaterialsList(materials)`: Structured parser for Google Drive files, YouTube videos, web links, and Google Forms.
  - `computeItemDiff(existingTask, assignment, isNew)`: Evaluates property modifications across title, deadline, description/instructions, and attachments.
  - `renderDiffViewer(diff)`: Renders GitHub-inspired dark commit diff viewers with monospace tables, property change pills, attachment badges, and split line numbers.
  - `showSyncSummaryModal(summary)` & `closeSyncSummaryModal()`: Controls modal lifecycle and renders sync overview stats pills (`Added`, `Updated`, `Up to date`).
  - `toggleSyncDiff(event, itemId)`: Smooth dropdown accordion toggle for individual diff cards.
  - Enhanced `syncAssignmentsToTasks()`: Tracks all item diffs and opens `#classroom-sync-modal` upon sync completion.
  - Enhanced `renderCourseDetails`: Embedded `#sync-classroom-tasks-btn-course` to allow syncing from within single-course views.
