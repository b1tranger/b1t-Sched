# Walkthrough - Task Export Selectable Vector PDF & Descriptive Filename Synchronization

Upgraded the Task Export PDF pipeline to deliver true vector PDF generation with 100% selectable and copyable text, complete Indic/Bangla script shaping, descriptive filename synchronization across both print and direct download flows, and an inline fallback link.

## Problem & Root Cause of Print Filename

When printing through an iframe or window via `print()`, Chromium-based browsers (Chrome, Edge, Opera, Brave) do not always read the iframe's internal title when suggesting the filename in the "Save as PDF" dialog. Instead, they default to the top-level parent window's `document.title` (`"b1t-Sched | Academic Task Scheduler"`). Because `|` is an illegal character in Windows filenames, the browser replaced it with an underscore, resulting in:
`b1t-Sched _ Academic Task Scheduler.pdf`
whereas the direct file download used the descriptive name:
`b1t-Sched_CSE_Current_Tasks_2026-09-05.pdf`.

## Changes Made

### 1. Task Export Module ([task-export.js](file:///d:/GitHub/[oU1TS]/b1t-Sched/js/features/task-export.js))

- **Synchronized Top-Level `document.title` in `printPdf()`**:
  - Prior to invoking `printFrame.contentWindow.print()`, temporarily sets `document.title = cleanTitle` (e.g., `b1t-Sched_CSE_Current_Tasks_2026-09-05`).
  - Chromium captures this title synchronously at print initiation, ensuring the native **Save as PDF** dialog suggests the exact matching descriptive filename (`b1t-Sched_CSE_Current_Tasks_2026-09-05.pdf`).
  - Restores the original title (`b1t-Sched | Academic Task Scheduler`) upon window `focus`, `afterprint`, or via a safety timeout:
    ```javascript
    const originalTitle = document.title;
    document.title = cleanTitle;

    let restored = false;
    const restoreTitle = () => {
      if (!restored) {
        restored = true;
        document.title = originalTitle;
        window.removeEventListener('focus', restoreTitle);
        window.removeEventListener('afterprint', restoreTitle);
      }
    };

    window.addEventListener('focus', restoreTitle);
    window.addEventListener('afterprint', restoreTitle);
    if (printFrame.contentWindow) {
      printFrame.contentWindow.addEventListener('afterprint', restoreTitle);
    }
    setTimeout(restoreTitle, 6000);
    ```
