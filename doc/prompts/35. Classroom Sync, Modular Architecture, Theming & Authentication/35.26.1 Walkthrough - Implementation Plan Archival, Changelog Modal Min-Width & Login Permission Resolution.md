### 3. Runtime Console Error Fixes
- [ui.js](file:///d:/GitHub/[oU1TS]/b1t-Sched/js/core/ui.js):
  - Declared `const isAdmin = typeof App !== 'undefined' ? App.isAdmin : false;` before calling `ApprovalManager.updateVisibility()`, fixing the `Uncaught ReferenceError: isAdmin is not defined`.
- [sw.js](file:///d:/GitHub/[oU1TS]/b1t-Sched/sw.js):
  - Fixed `Failed to execute 'clone' on 'Response'` in `staleWhileRevalidate()` by synchronously cloning the response before returning the promise.
- [db.js](file:///d:/GitHub/[oU1TS]/b1t-Sched/js/core/db.js) & [app.js](file:///d:/GitHub/[oU1TS]/b1t-Sched/js/core/app.js):

  - Added user-facing error notification when Firestore rejects unauthenticated reads, informing the user that `firestore.rules` must be deployed to Firebase or to log in with their email.
