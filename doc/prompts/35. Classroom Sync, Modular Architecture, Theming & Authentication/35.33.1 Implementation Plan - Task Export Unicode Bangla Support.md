# Task Export Unicode Bangla Support

Resolve the character encoding and font rendering bug where non-Latin (Bangla/Bengali) Unicode text (e.g. `"এক Group এ Maximum 4 জন থাকতে পারবে.."`) gets mangled into WinAnsi mojibake (`"*••Group • Maximum 4 œ¨¥¾•¤Çª¾°¬Ç..*"`) during export.

## User Review Required

> [!IMPORTANT]
> - **PDF Export Architecture**: Direct jsPDF vector string output with standard built-in fonts (`helvetica`) strips Unicode code points down to 8-bit (`code & 0xFF`), replacing Bangla characters with WinAnsi symbols (`œ`, `¨`, `¥`, `•`, etc.) and lacks complex Indic text shaping (conjuncts, vowel placement).
> - **Resolution Strategy**: Transition PDF generation in `js/features/task-export.js` to browser DOM-to-PDF rendering using `html2pdf.js` (already included in `index.html`), configured with explicit pure-white styling, retina canvas scale (2.0), `enableLinks: true` for clickable links, straight line task dividers, clean page-break avoidance, and standard ASCII page numbers.
> - **TXT & MD UTF-8 BOM**: Prepend standard UTF-8 Byte Order Mark (`\uFEFF`) to all file blobs generated via `downloadFile()`, ensuring Windows Notepad and text readers automatically decode Unicode Bangla text without falling back to Windows-1252/ANSI.
