# Implementation Plan - Auth Role Enforcement, Set-Details Lock, Mobile Tasks Filter & Login View Polish

Address cross-role authentication restrictions, role hopping prevention on set-details, compact mobile task filtering, notices permission fixes, and login hero layout.

## Proposed Changes

### 1. Default Light Mode for Logged-Out State
- In `index.html`, set `<head>` theme fallback script to `'light'` when no cached user profile/theme exists.
- In `js/core/auth.js` (`Auth.logout()`) and `js/core/app.js` (`App.handleUnauthenticatedUser()`), proactively remove `dark-mode` and `gray-mode` classes from `document.body` and `document.documentElement`.

### 2. Cross-Role Login Enforcement
- In `js/core/app.js`, cache registered signup intent role (`signup_role_<email>`) in `handleSignup()`.
- Add pre-checks in `handleLogin()` and authoritative post-auth checks in `handleAuthenticatedUser()` to block cross-role logins (students via Faculty tab or faculty via Student tab) with toast feedback.

### 3. Role Lockdown on Set-Details
- In `index.html`, hide `.faculty-signup-toggle` on `#set-details-view`.
- In `js/core/app.js` (`loadSetDetailsForm()`), bind `#set-is-faculty-checkbox.checked` to `currentLoginRole === 'faculty'` and disable manual toggling.

### 4. User Management Action Buttons & Filter
- In `js/core/app.js` (`renderUserList()`), hide "Make CR" button for faculty users, showing only "Make DptCoor".
- In `js/core/app.js` (`filterUsers()`), include `DptCoor` and `DptHead` accounts under the `Faculty` filter category.

### 5. Department Notices Permission Fix
- In `firestore.rules`, grant read access to `cr_notices` for faculty matching on department (`isFaculty() && resource.data.department == getUserDepartment()`) with null-guarded semester/section slicing.
- In `js/core/firestore-listener-manager.js`, bypass section task listener setup for faculty and route department notices through `listenForNewDepartmentNotices()` by department only.

### 6. Mobile Pending Tasks Compact Filter Dropdown
- In `index.html`, add `.task-filter-prefix` ("Filters: ") and `<select id="task-filter-select">` with placeholder "Set Filter" and external clear button.
- In `css/responsive.css` and `css/dashboard.css`, hide desktop filter buttons and display compact select dropdown on mobile screens.
- Synchronize dropdown choices with desktop radio pills in `js/core/app.js`.

### 7. Desktop Login 100vh Hero & Scroll-Down Guidance
- In `css/main.css`, wrap `#auth-card` in `.auth-hero-wrapper` (`min-height: 100vh`) and remove top gap via `.main-content.no-nav-padding`.
- Add `.login-scroll-indicator` with smooth bounce animation and click-to-scroll to `#login-footer-section`.

## Verification Plan
- Verify theme resets cleanly to Light Mode on logout.
- Verify student credentials cannot log in under Faculty tab and vice-versa.
- Verify mobile filter dropdown synchronizes with task list.
- Verify syntax and cache versions.
