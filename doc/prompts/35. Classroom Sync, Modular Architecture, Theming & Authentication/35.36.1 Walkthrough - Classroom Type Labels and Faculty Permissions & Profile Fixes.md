# Walkthrough: Classroom Type Labels, Faculty Permissions & Profile Fixes

This walkthrough details the implementation and validation of the changes resolving the Classroom Task Update Summary modal item type badges, Faculty session auto-logout on token refreshes, Department notices permissions in `cr-notice.js`, and Faculty preview mode tasks and profile card `null` text removal.

---

## Changes Summary

### 1. Classroom Feature (`js/features/classroom.js` & `css/classroom.css`)
- **Item Type Categorization**:
  - In `computeClassroomChanges()`, coursework items are tagged with `type: 'assignment'`, announcements with `type: 'announcement'`, and coursework materials with `type: 'material'`.
  - Added full diffing support for coursework materials across sync cycles (`prevMaterials` vs `freshMaterials`).
  - Passed `prevMaterials` and `freshMaterials` in `refreshData()` and `handleTokenResponse()`.
- **Sync Summary Badges & Pills**:
  - In `showSyncSummaryModal()`, replaced hardcoded `'Added Task'` with dynamic labels (`Added Announcement`, `Added Assignment`, `Added Material`, `Updated Announcement`, etc.).
  - Added dedicated type pills `<span class="sync-type-pill type-${itemType}">` with custom icons (`fa-bullhorn`, `fa-folder-open`, `fa-clipboard-list`).
- **Coursework Task Sync for Faculty**:
  - In `syncClassroomWorkToTasks()`, ensured `taskData.semester` and `taskData.section` are set to `null` and `addedByRole: 'Faculty'` when syncing as a faculty user or in faculty preview mode.
- **Styling**:
  - Added styles for `.sync-type-pill` in `css/classroom.css` with dedicated theme-aware color variants (`.type-assignment`, `.type-announcement`, `.type-material`).

### 2. Core Authentication & Profile (`js/core/app.js` & `js/core/ui.js`)
- **Faculty Session Stability**:
  - In `handleLogin()`, set `this._isExplicitLoginAttempt = true` upon form submission.
  - In `handleAuthenticatedUser()`, restricted cross-role mismatch checks exclusively to explicit interactive logins (`this._isExplicitLoginAttempt`).
  - Synchronized `this.currentLoginRole = this.isFaculty ? 'faculty' : 'student'` and saved to local storage, preventing background token refreshes, tab refocus, or page reloads from triggering `Auth.logout()`.
- **Navbar Profile Card `null` Text Removal**:
  - In `UI.updateUserDetailsCard()`, filtered out `null`, `undefined`, and the string `'null'`, cleanly showing `${department}` (e.g. `CSE`) instead of `CSE • null • null`.
- **Admin Faculty Preview Mode Profile Display**:
  - In `applyPreviewRole('Faculty')`, updated the user details card to display department without semester/section (`UI.updateUserDetailsCard(email, dept, null, null)`).
  - In `applyPreviewRole('none')`, restored the user details card with the Admin's authentic semester and section.
- **Faculty Task Role Attribution**:
  - In `handleAddTask()`, passed `addedByRole: 'Faculty'` when `this.isFaculty` is active.

### 3. Database Layer & Department Notices (`js/core/db.js`, `js/features/cr-notice.js` & `js/core/firestore-listener-manager.js`)
- **Faculty Tasks Loading**:
  - In `DB.getFacultyTasks()`, updated the query to `.where('department', '==', department).where('status', '==', 'active')` and added client-side filtering for tasks where `task.addedByRole === 'Faculty'` OR `(!task.semester && !task.section)` OR `(task.semester === 'null' && task.section === 'null')`.
  - Ensures tasks created in Faculty preview mode, Admin faculty tasks, and direct faculty tasks are loaded seamlessly.
- **Task Creation Role Attribution**:
  - In `DB.createTask()`, honored `data.addedByRole` if supplied, and set `addedByRole = 'Faculty'` when `App.previewRole === 'Faculty'` or when semester/section are `null`.
- **Department Notices Security Rules Compliance**:
  - In `cr-notice.js`, scoped the department notices query to `.where('department', '==', userDept).where('isDepartmentNotice', '==', true)` with error fallback handling, eliminating `FirebaseError: Missing or insufficient permissions`.
  - In `firestore-listener-manager.js`, added `.where('isDepartmentNotice', '==', true)` to `listenForNewDepartmentNotices()`.
