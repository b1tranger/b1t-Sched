# Walkthrough - Faculty & Student ID Login, 3-Row Install Prompt & Login Scroll Reset

Summarizes the implementation of flexible credentials lookup for student and faculty login, redesign of the install prompt to a 3-row layout with solid backgrounds, and viewport scroll fix.

## Changes Completed

1. **Faculty & Student ID / Initials Flexible Login**:
   - `DB.getEmailByStudentId()`: Normalized student ID lookup across string, stripped, and numeric formats.
   - `DB.getEmailByFaculty()`: Looked up faculty by initial, studentId, or facultyId in memory without composite query index restrictions.
   - `App.handleLogin()`: Removed restrictive 10-16 digit checks on login, allowing flexible format entry. Retained strict 10-16 digit requirement on set-details and email-only sign-up.

2. **Web App Install Prompt: 3-Row Architecture & Solid Background**:
   - `index.html` & `css/components.css`: Created 3-row vertical layout (Row 1: Header/Icon + Title, Row 2: Description, Row 3: Action buttons).
   - `css/colors.css`: Defined `--bg-card` token across `:root`, `body.dark-mode`, and `body.gray-mode`.
   - Set 100% solid, non-transparent card backgrounds for Light (`#ffffff`), Dark (`#242424 !important`), and High Contrast (`#141414 !important`).

3. **Prevent Downward Scroll on Login Refresh & Logout**:
   - `Router.init()`: Set `history.scrollRestoration = 'manual'`.
   - `Router.showView()`, `Auth.logout()`, `App.handleUnauthenticatedUser()`, and `UI.showLoading(false)`: Enforced instant scroll-to-top (`window.scrollTo({ top: 0, left: 0, behavior: 'instant' })`).

4. **Release & Maintenance**:
   - Bumped `CACHE_VERSION` in `sw.js` to `v2.53.6`.
   - Updated `changes.json` with `v2.53.6`.
   - Documented in `doc/DOCUMENTATION.md` under `# 04.09.26`.
