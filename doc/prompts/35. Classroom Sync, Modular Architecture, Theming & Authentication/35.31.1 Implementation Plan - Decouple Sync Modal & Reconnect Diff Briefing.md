# Implementation Plan - Decouple Sync Modal & Reconnect Diff Briefing

Modify the Classroom interaction workflow so the **Sync** button (`Classroom.syncAssignmentsToTasks`) no longer opens the `#classroom-sync-modal` (providing lightweight toast notifications instead), leaving the diff summary modal exclusively to the **Refresh** button (`Classroom.refreshData()`). Additionally, when a user reconnects their Google Classroom account after an expired session, compute differences against their cached data and automatically display the `#classroom-sync-modal`.

## Updated Comparison Overview

| Dimension | **Sync Button** (`syncAssignmentsToTasks`) | **Refresh Button** (`refreshData`) | **Reconnect Action** (`handleAuthSuccess`) |
| :--- | :--- | :--- | :--- |
| **Element / Trigger** | `#sync-classroom-tasks-btn` / `#sync-classroom-tasks-btn-course` | Refresh button (`.classroom-back-btn` with `fa-redo-alt`) | Reconnect Classroom button (`.classroom-reconnect-btn`) |
| **Visible To** | **Admin and CR only** (`App.isAdmin \|\| App.isCR`) | **All authenticated users** | **Users with expired tokens** (`hasExpiredSession === true`) |
| **Active Tabs** | **To-Do tab only** (`viewType === 'todo'`) | All tabs (To-Do, Notices, Materials) | Cached content footer banner (All views) |
| **Data Flow** | Cached assignments $\rightarrow$ **Firestore `tasks` Collection** | Google Classroom APIs $\rightarrow$ **Local Cache & Memory** | Google Classroom APIs $\rightarrow$ **Local Cache & Memory** |
| **Database Writes** | **Yes** (Creates/updates shared schedule tasks) | **No** (Strictly read-only for shared tasks) | **No** (Strictly read-only for shared tasks) |
| **Task Completion** | **No effect** (Does not touch completion status) | **Yes** (Reconciles turned-in/graded assignments in Pending Tasks) | **Yes** (Reconciles turned-in/graded assignments in Pending Tasks) |
| **Opens Diff Modal** | **No** (Provides non-intrusive toast notifications) | **Yes** (`#classroom-sync-modal`) | **Yes** (`#classroom-sync-modal` comparing cached vs live) |

## User Review Required

> [!NOTE]
> - **Sync Button Feedback**: When an Admin/CR clicks **Sync**, instead of displaying the large `#classroom-sync-modal`, the app will show concise feedback via `UI.showToast()`:
>   - Success: `Synced assignments: X added, Y updated.`
>   - Up to date: `All assignments are up to date.`
>   - Empty: `No eligible assignments found to sync.`
> - **Reconnect Session Diff**: When a user's token expires, the app preserves cached data with the sticky bottom banner (`updateBottomCachedFooter`). Clicking **Reconnect Classroom** completes OAuth login, compares newly fetched assignments and announcements against the cached data, reconciles task completions, and automatically opens `#classroom-sync-modal` showing all changes that occurred while the session was expired.

## Proposed Changes

### Classroom Feature Module

#### [MODIFY] [js/features/classroom.js](file:///d:/GitHub/[oU1TS]/b1t-Sched/js/features/classroom.js)

1. **Decouple `syncAssignmentsToTasks()` from `#classroom-sync-modal`**:
   - Replace all `this.showSyncSummaryModal(...)` calls in `syncAssignmentsToTasks()` with `UI.showToast()` notifications:
     - If no assignments: `UI.showToast('No assignments found to sync.', 'info')`.
     - If no assignments with due dates: `UI.showToast('No assignments with due dates found to sync.', 'info')`.
     - On completion: If `addedItems.length === 0 && updatedItems.length === 0`, show `UI.showToast('All assignments are up to date.', 'info')`. Otherwise, show `UI.showToast(`Synced assignments: ${addedItems.length} added, ${updatedItems.length} updated.`, 'success')`.
2. **Extract Reusable Classroom Diff Computation**:
   - Create helper method `computeClassroomChanges(prevAssignments, prevAnnouncements, freshAssignments, freshAnnouncements)` returning `{ added, updated, unchanged }`.
   - Update `refreshData()` to utilize `computeClassroomChanges()` for computing and displaying `#classroom-sync-modal`.
3. **Handle Expired Session Reconnection Diff**:
   - In `handleAuthSuccess(tokenResponse)`:
     - Check `const wasExpired = this.hasExpiredSession;`.
     - If `wasExpired` is true, snapshot existing cached assignments and announcements before clearing or fetching fresh data.
     - Await `fetchCoursesAndLoadAll()`.
     - Reconcile task completion via `await this.syncTurnedInAssignmentsToUserCompletions(freshAssignments)`.
     - Run `computeClassroomChanges()` between the cached snapshot and fresh data.
     - Call `this.showSyncSummaryModal(diffSummary)` to brief the user on all newly added and updated coursework/announcements.
