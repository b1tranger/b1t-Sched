# Implementation Plan - Localhost Setup, Semester Auto-Update & Bulk User Semester Migration

Configure the project for local execution on `localhost`, implement profile logic for automatic semester increments after each semester ends (every January and July), and run a bulk manual update for all existing user semester values.

## User Review Required

> [!IMPORTANT]
> - **Semester Auto-Update Schedule**: Semesters end in June and December. Every start of July (`YYYY-07`) and January (`YYYY-01`) will automatically increment a student's semester by 1 step (e.g. `1st` &rarr; `2nd`, ..., `7th` &rarr; `8th`, `8th` &rarr; `alumni / special`).
> - **`alumni / special` Option**: Reaching semester 8 and incrementing will transition the user to `"alumni / special"`. Once a user reaches `"alumni / special"`, the semester setting in Profile Settings becomes readonly and cannot be changed further.
> - **Bulk Semester Update**: We will run a script to update all student user profiles in Firestore right now (for the July 2026 transition) incrementing their current semester by +1 step and setting their `lastSemesterCycle` to `"2026-07"`.
