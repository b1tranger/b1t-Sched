# UITS Event Raiders RSS Integration Implementation Plan

Integrate the **UITS Event Raiders** live RSS / JSON feed (`ou1ts/events`) into **b1t-Sched** across desktop and mobile layouts according to [INTEGRATION_GUIDE.md](file:///c:/Users/gsmur/Documents/GitHub/[oU1TS]/b1t-Sched/doc/rss-events-integration/INTEGRATION_GUIDE.md).

## Requirements & Scope

1. **Feed Integration**:
   - Primary: Fetch live contests, hackathons, and symposiums from `https://ou1ts.github.io/events/raids.json` (Native JSON feed with full-fidelity schemas: dates, fees, sub-events, registration deadlines, external links).
   - Fallback: XML RSS parsing (`https://ou1ts.github.io/events/feed.xml`) and `localStorage` caching (30-min TTL) to ensure offline resilience and rapid loading.
   - Filter active/future events (filter out past events based on end date and status).

2. **Desktop Layout**:
   - Display the UITS Event Raiders section below the Upcoming Events section within the desktop sidebar (`.dashboard-sidebar.desktop-only`).
   - The desktop sidebar maintains sticky positioning (`position: sticky; top: ...; max-height: calc(100vh - 120px); overflow-y: auto;`) as the pending tasks section is vertically scrolled.

3. **Mobile Layout**:
   - In the mobile Events sidebar (`#events-sidebar`), UITS Event Raiders view is initially hidden, displaying the b1t-Sched Events view by default.
   - A prominent **arrowhead button** is placed on the left border of the mobile sidebar.
   - Clicking this arrowhead button toggles between the **b1t-Sched Events view** and the **UITS Event Raiders view** with smooth transitions and updated header indicators.
