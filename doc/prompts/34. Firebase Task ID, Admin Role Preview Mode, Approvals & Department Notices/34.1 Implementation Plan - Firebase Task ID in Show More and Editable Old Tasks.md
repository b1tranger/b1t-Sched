# Implementation Plan - Firebase Task ID in Show More and Editable Old Tasks

Display the Firestore task ID within the "Pending Tasks" cards when the "Show more" description toggle is expanded, and allow users with matching editing roles (Admins, and users/CRs/Faculty for tasks they created) to edit tasks in "Old Tasks". When deadlines are extended to a later deadline or removed, tasks automatically reappear in "Pending Tasks".

## Proposed Changes

### UI & Styling Updates

#### [MODIFY] [css/components.css](file:///d:/GitHub/[oU1TS]/b1t-Sched/css/components.css)
- Switch `.task-description-text.expanded+.task-added-by-hidden` to general sibling combinator `.task-description-text.expanded ~ .task-added-by-hidden` so all hidden info blocks (Added by and Task ID) reveal when expanded.
- Add `.task-id-info` and `.task-id-code` styling with monospace formatting and `user-select: all` for quick copying.

#### [MODIFY] [css/dashboard.css](file:///d:/GitHub/[oU1TS]/b1t-Sched/css/dashboard.css)
- Add styling for `.old-task-actions` and alignment within `.old-task-item`.

#### [MODIFY] [js/ui.js](file:///d:/GitHub/[oU1TS]/b1t-Sched/js/ui.js)
- In `renderTaskCard`: Insert the Firebase task ID (`<p class="task-id-info task-added-by-hidden"><span class="task-id-label">Task ID:</span> <code class="task-id-code">${task.id}</code></p>`) inside `.task-description-wrapper`.
- In `renderOldTasks(tasks, isAdmin, currentUserId)`: Render an edit button on each old task card if `isAdmin || (currentUserId && task.addedBy === currentUserId)`.
