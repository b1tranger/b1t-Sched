# Walkthrough - User Role Display & Admin Role Preview Mode

Implemented user role status display beneath the Student ID in Profile Settings, and added an interactive "Preview as" role simulation system for Admins using temporary `sessionStorage` with a floating global Exit Preview banner.

## Changes Made

### 1. User Role Status Display in Profile Settings
- [index.html](file:///d:/GitHub/[oU1TS]/b1t-Sched/index.html):
  - Added `#profile-role-wrapper` beneath `#profile-student-id` with `#profile-role-badge` and `#profile-role-preview-tag`.
- [js/profile.js](file:///d:/GitHub/[oU1TS]/b1t-Sched/js/profile.js):
  - Added `Profile.updateRoleDisplay()` to dynamically calculate the effective role (`Admin`, `Faculty`, `CR`, `Student`, `Blocked`) and render the colored role badge.
  - Automatically appends `(preview)` when in preview mode.

### 2. Admin Role Preview Simulation System
- [index.html](file:///d:/GitHub/[oU1TS]/b1t-Sched/index.html):
  - Added `#admin-preview-control` containing `#admin-preview-select` (`Admin (Default)`, `Faculty`, `CR`, `Student`, `Blocked`) and `#exit-preview-profile-btn`.
  - Added floating top-centered `#admin-preview-banner` with `#admin-preview-role-text` and `#exit-preview-banner-btn`.
- [css/dashboard.css](file:///d:/GitHub/[oU1TS]/b1t-Sched/css/dashboard.css):
  - Styled `#admin-preview-banner` as a floating glassmorphism pill with smooth slide-down animation and responsive scaling.
  - Added `.preview-tag`, `.admin-preview-control`, `.admin-preview-select`, and dark/gray mode overrides.
- [js/ui.js](file:///d:/GitHub/[oU1TS]/b1t-Sched/js/ui.js):
  - Added `UI.updatePreviewBanner(isPreview, previewRole)` to manage banner, tags, and exit button states.
- [js/app.js](file:///d:/GitHub/[oU1TS]/b1t-Sched/js/app.js):
  - Added `realRoles` tracking and `previewRole` state.
  - In `handleAuthenticatedUser()`, checks `sessionStorage.getItem('b1t_admin_preview_role')` for active previews.
  - Added `App.applyPreviewRole(role, reloadData)`:
    - Sets active UI role flags (`this.isAdmin`, `this.isCR`, `this.isFaculty`, `this.isBlocked`).
    - Stores role in `sessionStorage` (cleared automatically upon browser/session exit).
    - Calls `UI.toggleAdminControls()`, `UI.toggleBlockedUserMode()`, `UI.updateSectionVisibility()`, and `App.loadDashboardData()`.
  - Added `App.exitPreview()` to reset back to default Admin role with one click.
  - Wired event listeners for `#exit-preview-banner-btn` and `#exit-preview-profile-btn`.
- [js/profile.js](file:///d:/GitHub/[oU1TS]/b1t-Sched/js/profile.js):
  - Displayed "Preview as" dropdown exclusively when actual user is Admin (`App.realRoles?.isAdmin`).
  - Added change event listener to switch preview roles instantly.

### Manual Verification Checklist
1. **Regular User**:
   - Opens Profile Settings: Shows Student ID and "Role: Student" (or CR/Faculty).
   - "Preview as" dropdown is hidden.
2. **Admin User**:
   - Opens Profile Settings: Shows "Role: Admin" and "Preview as:" dropdown.
   - Selecting "Faculty": Role updates to "Faculty (preview)", admin controls toggle to Faculty view, and top floating banner appears.
   - Selecting "CR": Role updates to "CR (preview)", CR controls appear, and banner reflects CR.
   - Selecting "Student": Role updates to "Student (preview)", admin/CR buttons hide, and banner reflects Student.
   - Selecting "Blocked": Role updates to "Blocked (preview)", restricted user banner appears.
3. **Exit Preview**:
   - Clicking "Exit Preview" on the floating top banner or inside Profile Settings instantly clears `sessionStorage`, removes the banner, and restores default Admin capabilities.
   - Starting preview mode, closing the tab, and reopening in a new session automatically resets to default Admin.
