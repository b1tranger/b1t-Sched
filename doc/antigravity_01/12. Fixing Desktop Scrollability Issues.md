### Planner Response

I have identified the issue that was preventing the vertical scrolling in the CR notice section on desktop view and applied the fix to `css/notice.css`.

### What caused the issue:
The desktop layout uses a CSS Grid and Flexbox combination (`.notice-desktop-grid` and `.notice-column`). By default, flex/grid items have a minimum height equal to their contents (`min-height: auto`), meaning the columns were stretching out infinitely as notices were added instead of triggering the scrolling behavior. Because the main grid container had `overflow: hidden;`, the over-stretched items were simply clipped, hiding the bottom content without showing a scrollbar.

### What was changed:
I added `min-height: 0;` to both `.notice-column` and `.notice-column-content`. This explicitly tells the browser that these flex/grid items are allowed to shrink below their natural content height, which in turn confines the column to the viewable modal height and perfectly triggers `overflow-y: auto` to add a scrollbar when the notices exceed the view space.

You should now see the vertical scrollbar properly attached to the notices column on desktop! Let me know if you need any further adjustments.
